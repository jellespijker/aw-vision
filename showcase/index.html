Gallery & Timeline Explorer

The central dashboard offers a full chronological stream of your desktop history. Hover or click to open the Lightbox Modal, where you can view raw OCR captures, edit custom user-context notes, and see historical vision analyses grounded in temporal neighbor snapshots.

  • Full OCR Extraction: Review precise text segments extracted from the screen.
  • Context Notes: Annotate snapshots with custom details to guide future classifications.
  • Time-Machine History: Effortlessly filter snapshots by app category or active project.

Smart Project Allocation

Analyze your focus times across various workspace project keys. Using both heuristics and deep semantic vision mappings, the pipeline groups screenshots into projects to track your effort automatically.

  • Client Timeline: A visual chronological breakdown of project segments.
  • Dynamic Hour Tracking: Aggregate exact hours spent on specific client keys like PRJ-2026-089.
  • Bayesian Classification: Combines app rules with semantic content checks for robust mapping.

Three-Phase Batch Processing

The backend coordinates CPU-aware bulk sweeps during idle windows, processing screenshots in sequential stages:

  1. Phase 1: OCR Extraction: Extracts raw code and texts from your captures.
  2. Phase 2: Vision Analysis: Generates semantic tags, description overlays, and project categorization.
  3. Phase 3: Embedding Commit: Commits layouts and summaries to LanceDB as vector indices.

Memory Agent Q&A

Leverage the LangGraph ReAct agent to retrieve context instantly. Ask questions like "What was I working on yesterday morning?" or "Find files where I edited the Vite config."

  • Semantic Search Tool: Scrapes local LanceDB vectors for content matches.
  • External Integrations: Connects to MCP servers (GitHub, Jira, etc.) to query files or tickets in parallel.
  • Guidance Skills: Inject Claude SKILL.md guidelines into the agent's prompts for structured responses.

High-Fidelity Customization

Customization is built directly into settings. Define local model names, configure prompting templates, manage local/remote Model Context Protocol (MCP) integrations, and upload Claude Skills.

  • Model Settings: Toggle Ollama or Gemini for OCR, Vision, and Embedding loops.
  • Skill Management: Connect expert files dynamically to specific pipeline prompts.
  • Secured Secrets: API keys and connection tokens are encrypted with hardware-derived keys.

Local-First. 100% Private.

Because desktop captures contain highly sensitive information (credentials, emails, code, documents), aw-vision was built with privacy-by-design principles:

Local Processing

All screenshots are stored locally and processed via offline Ollama models by default. Your data never leaves your device unless you opt-in to cloud services.

Retention Lifecycle

Raw and processed image files are automatically pruned from disk after 14 days, protecting storage size and minimizing physical security exposure.

Permanent Vector Index

While raw images are wiped to preserve disk space, their text indices, descriptions, and semantic coordinates remain queryable forever in LanceDB.

Encrypted Credentials

API keys and credentials for cloud services (like Gemini API) or MCP servers are AES-256 encrypted using a hardware-derived key before saving to disk.
